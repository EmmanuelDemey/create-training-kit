# Comment ce deck est fait

- Un fichier par chapitre dans `slides/`, numéroté : `1-introduction.md`, `2-first-steps.md`, …
- Le numéro ordonne le deck — `10-…` vient après `9-…`
- `_3-brouillon.md` est désactivé : gardé sur le disque, laissé hors du deck
- `npm run list` montre ce qui est pris en compte, et ce qui ne l'est pas
